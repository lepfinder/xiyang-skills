# 希扬 IP 角色定义

## 角色定位

“希扬”是正文配图的标志性视觉 IP。
在每张配图中，希扬以一个**戴圆眼镜、留刺刺短发的 Q 版小男孩**形象出现。它并不是纯装饰的吉祥物，而是负责在抽象的系统和逻辑中扮演“探索者”、“重构者”或“解答者”的行动主体。

## 外形设计（基于 ip.jpg 特征提取）

- **头部特征**：
  - 留着一头**刺刺的、蓬松的黑色短发**（Spiky black hair）。
  - 戴着一副大大的**黑色圆框眼镜**（Round black-framed glasses），遮住大半个脸，显得好奇且富有智慧。
  - 大大的圆点眼睛，眼神清澈、充满好奇。
- **服饰与身体**：
  - 穿着一件**深蓝色短袖 T 恤**（Dark blue T-shirt）与**米色/卡其色短裤**（Beige shorts）。在极简配图中，T 恤可填充为克制的深蓝色或保留黑色线稿。
  - **光脚**（Barefoot），四肢为简笔手绘线条。
  - 身体轮廓有自然的、微微抖动的手绘线条感，拒绝工业矢量化。
- **表情气质**：
  - 平静、温和、专注中带着强烈的好奇心。
  - 有时会做出托腮思考（脑袋上方出现橙黄色/蓝色灵感灯泡）、用手指引方向或向上观察的动作。

## 性格与行为倾向

- **性格**：聪慧、专注、温和、有探求欲。
- **作风**：它是一个“解题者”或“系统的探索者”。在配图中，它负责去理解、梳理和点亮复杂的逻辑，动作大方、得体。
- **温和冷幽默**：不流于俗套的过度卖萌，通过与画面中怪诞物件的交互来传递冷幽默和智慧感。

### 常见职责

让希扬承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。

## 禁止

- **不要在画面上写「希扬」「Xiyang」或任何 IP 名字、角色名牌、头顶标签**——名字只存在于技能/沟通层，成图里只有人物形象。
- 不要把希扬画成过度可爱的吉祥物。
- 不要画成儿童卡通角色。
- 不要给希扬复杂服装、表情包、闪亮眼睛。
- 不要让希扬只是站在角落里看。
- 不要让希扬抢走结构表达。
- 不要把希扬画得太商业、太圆润、太精致。

## 判断标准

如果去掉希扬，图的核心隐喻还能完全成立，说明希扬太装饰了；要重写提示词，让希扬成为动作主体。止出现红绿交织等杂乱服饰。
- 希扬必须参与逻辑动作，不能只是呆呆地站在角落当背景板。
- 保持手绘质朴感，绝对禁止使用 3D 渲染、渐变阴影或工业圆角的完美矢量图。
